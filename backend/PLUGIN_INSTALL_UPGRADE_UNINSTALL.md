# 插件安装、升级、停用与卸载

## 安装

1. 检查 Discuz X5、PHP 扩展、数据库版本、HTTPS、文件权限和服务端加密主密钥。
2. 安装 `stk_auth`，执行 V1.0.0 认证与共享表迁移，注册后台菜单和计划任务。
3. 安装 `stk_project`，执行项目基础迁移，注册后台菜单。
4. 创建最小权限管理员角色；使用线上已有 `admin` 管理员账号，凭据只从本机 `ADMIN_ACCESS_HANDOFF.local.md` 交接，首次登录后建议修改密码。
5. 导入测试分类和明确标记的测试项目；生产数据不得来自虚构静态 JSON。
6. 运行 API、权限、审计、健康和卸载保护测试。

## 升级

- 按插件当前版本和目标版本逐个执行迁移；每步事务化记录。
- 数据迁移与新代码必须满足向后兼容窗口，确保 APK 覆盖安装期间旧客户端不会立即崩溃。
- 任何不可逆迁移必须有备份、影响说明和恢复脚本；没有恢复方案不得上线。
- V1.1 起每次升级都验证 Android 上一版登录态、Room 数据和服务器数据库兼容。

## 停用

停用插件不得导致 Discuz 管理后台无法进入。用户 API 返回明确维护/停用错误，不能暴露 PHP 错误页面。恢复时不得丢失配置和数据。

## 卸载

默认仅移除菜单、Hook、计划任务和代码，不删除表。只有超级管理员明确选择“备份后永久删除数据”、二次确认并通过权限校验时，才运行数据删除脚本。卸载行为写审计日志。
