# 通用模板适配说明

本项目参考了用户提供的 `Universal_AI_Assisted_App_Development_Template_V1.1.0_20260805` 的有效原则：机器合同、一一映射、UI Token、Page/State/Interaction ID、CI 同源 APK、覆盖安装、视觉回归、桌面交付和上下文防漂移。

为符合商推客“多写代码、少做无用验证”的要求，本包没有复制重型循环治理、重复规划或多层审批流程。保留的脚本只负责合同校验、效果图就绪、视觉差异、发布来源和桌面复制；不会自动反复选择任务或进行无边界检查。

通用模板中的示例品牌、域名、仓库、功能、版本和占位符均未带入本项目。本包所有项目事实均来自 `PROJECT_CONTEXT.yaml`。
