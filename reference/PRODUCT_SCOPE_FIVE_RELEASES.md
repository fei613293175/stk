# 商推客五版本产品范围索引

本文件用于防止长期功能遗漏，但不是当前任务清单。Codex 当前只能执行根目录 `CURRENT_TASK.md`。

## V1.0.0：登录注册与原生底座

- Compose 原生框架、统一设计 Token 和公共组件；
- 手机号密码登录、手机号短信登录、注册不发送短信；
- 登录、注册、发送短信前的安全验证码；
- Token、会话、退出登录；
- Discuz `stk_auth` 插件、认证 API、后台基础设置；
- 阿里云短信、验证码记录、注册用户列表在 Beta 2/Beta 3 接入；
- 登录后提供首页、发布、我的三项基础导航。

## V1.1.0：项目浏览

- 首页单列项目流、分类、搜索、游标分页和自动加载更多；
- 本地缓存、空数据、弱网、离线和失败状态；
- 项目详情、图片查看、发布者资料、联系方式与外部应用跳转；
- 后台项目查询和首页展示配置。

## V1.2.0：发布与审核

- 标题、简介、分类、联系方式和多图发布；
- Android 系统照片选择器、压缩、进度、失败重试；
- 我的发布、编辑、下架、删除、驳回后重提；
- 后台分类、发布配置、图片限制、项目审核和审核日志。

## V1.3.0：我的与运营展示

- 用户资料卡、会员状态、佣金账户、任务账户；
- 会员权益卡、道具中心和常用功能占位页面；
- 后台人工会员管理、账户查询、运营文案和入口显示配置；
- 本版本不实现支付、提现、返佣结算或道具购买。

## V1.4.0：生产发布

- 正式签名、覆盖安装、版本更新、APK 下载页；
- `stk-api`、`stk-admin`、`stk-static`、`stk-download` 域名与 TLS；
- App Links、维护模式、备份、回滚和生产安全加固；
- 五版本关键链路回归与最终交付。

## 长期明确不自动扩展

除非项目拥有者另行授权，不开发 iOS、PC 用户前端、横屏、平板专用布局、私聊、红包、分销、真实支付、提现、佣金结算和复杂推荐算法。
