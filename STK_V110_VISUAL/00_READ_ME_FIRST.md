# 商推客 V1.1.0 详细视觉开发覆盖包

本包用于在稳定的 V1.0.0 代码基础上，开发和完善 **V1.1.0 项目浏览**。包内包含本版本全部 **45 张批准页面状态效果图**，覆盖 **9 个运行页面/弹层**。

## 本包包含

- V1.1.0 页面状态效果图：**45 张**；
- 页面、状态、交互、API、数据库、后台页面和后台配置参考；
- 6 个轻量开发批次；
- Windows/Linux 安装脚本；
- 不包含 V1.2.0 及后续页面，避免提前扩大范围。

## 执行原则

1. 这是当前仓库的增量覆盖包，不是重新初始化 Android 或 Discuz 工程的开发包。
2. 保留已经能运行、登录、注册、退出和覆盖安装的 V1.0.0 代码、签名、Gradle、SDK、数据库迁移和 CI。
3. 45 张图是 9 个页面/弹层的不同 UI 状态，不是 45 个独立 Screen，也不是 45 次模拟器或 CI 门禁。
4. **第一份 V1.1.0 测试 APK不得等待全部 45 个状态完成。**首页正常内容、项目详情、搜索/分类基本链路和 APK 构建通过后，应立即交付 `1.1.0-beta.1`；随后再完善全部状态并交付 beta.2/正式版。
5. 效果图只决定布局、颜色、字号、圆角、间距、高度与反馈样式；图片中的项目名称、头像、浏览量、联系方式和日期均为示例数据，不能据此新增功能。
6. 本版本只做项目浏览，不做发布、图片上传、审核、会员购买、佣金结算或支付。
7. 不恢复 API 37 阻断、45 图自动截图、每图单独提交或生产发布门禁。

## 安装到当前仓库

Windows：

```powershell
powershell -ExecutionPolicy Bypass -File .\STK_V110_VISUAL\scripts\install-visual-overlay.ps1 -RepoPath .
```

Linux：

```bash
bash ./STK_V110_VISUAL/scripts/install-visual-overlay.sh .
```

脚本只复制视觉资料、合同和版本任务文件，不覆盖业务代码、`AGENTS.md`、构建配置或 GitHub Actions。
