# V1.1.0 页面状态与效果图执行策略

## 资产范围

- 当前版本运行页面/弹层：9 个；
- 当前版本详细状态效果图：45 张；
- 这些图片全部是实现参考，不是 45 个独立页面或 45 次自动视觉门禁。

## 正确实现方式

1. 同一页面使用一个 Screen、一个 ViewModel 和明确的 UI State 表达加载、内容、空、错误、离线、分页和超时。
2. 复用公共卡片、骨架、错误、空状态、Dialog、Snackbar 和 Bottom Sheet。
3. 第一份 V1.1.0 测试 APK只要求最小浏览链路可运行；45 状态在后续批次补齐。
4. 每个正式页面人工抽查至少一个 canonical 状态；其余状态使用组件测试、ViewModel 测试和 Fixture 触发。
5. 禁止自动覆盖效果图基线；图片只决定视觉，功能以合同为准。

## 视觉抽查建议

优先抽查：

- `HOME-001-S02` 首页正常内容；
- `HOME-001-S08` 首页离线缓存；
- `HOME-002-S04` 搜索有结果；
- `HOME-003-S01` 分类列表；
- `HOME-004-S02` 公开项目详情；
- `HOME-OV-001-S02` 图片缩放；
- `HOME-OV-002-S02` 微信操作；
- `COM-OV-001-S02` 外链被阻断。

字体抗锯齿、状态栏时间等非结构性差异不得造成长时间循环；结构、间距、颜色、组件缺失和错误交互才需要修复。
