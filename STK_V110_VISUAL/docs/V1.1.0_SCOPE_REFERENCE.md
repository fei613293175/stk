# V1.1.0：项目浏览范围参考

## 本版必须完成

- 首页项目流、下拉刷新、游标分页、分页失败局部重试；
- 本地缓存与离线展示；
- 项目搜索与项目分类；
- 项目详情、图片查看、浏览计数；
- 手机、微信、QQ、网址联系方式；
- 受控外链、目标 App 未安装和无效目标回退；
- `stk_project` 浏览后端与管理后台。

## 对应后端范围

- API：4 个；
- 数据库实体：4 个；
- 后台页面：5 个；
- 后台配置：12 个；
- 新增交互：34 项；
- 详细视觉状态：45 个。

详细映射位于 `contracts/`，图片不得替代 API、数据库或后台合同。

## 明确不做

- 用户发布、图片上传、草稿、编辑、下架、删除和审核（V1.2.0）；
- 收藏、评论、私聊、搜索历史；
- 保存项目图片到相册；
- 会员购买、佣金结算、任务奖励和支付；
- 生产 CDN/DNS/TLS、下载站和最终 RC（V1.4.0）。

## 快速交付顺序

```text
复用 V1.0.0 稳定工程
→ 首页正常内容与详情纵向链路
→ 第一次构建成功立即交付 beta.1

→ 覆盖安装与 Owner 测试

```
