
# V1.4.0：生产发布与最终 RC

## 必须完成

- 可选/强制更新、APK 下载/校验/安装回退。
- App Links、下载页、生产域名/TLS、维护模式。
- 固定正式签名、从 1.3.0 覆盖安装、生产备份/回滚。
- API36 6 条关键流、8 个更新代表状态、每个正式页面一个 canonical 回归。

## 明确不做

- 新增支付、分销、红包等业务。
- 把 API37 兼容失败作为发布阻断。

## 开发顺序

```text
复用现有成功环境 → 先打出测试 APK → 纵向完成当前功能 → Fast CI
→ 手动 API36 版本验收 → 代表视觉检查 → 覆盖安装 → 桌面交付
```

## 关闭清单

- [ ] 生产 API/后台/静态/下载域名健康。
- [ ] APK SHA、签名、版本和回滚资料齐全。
- [ ] 最终 Owner 验收通过。

生产部署只在 V1.4.0 阻断。API37 只提供兼容报告，不阻断本版本。
