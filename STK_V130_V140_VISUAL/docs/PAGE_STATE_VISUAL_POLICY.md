
# 页面、状态与效果图执行策略

## 1. 资产数量

- 页面/覆盖层/规范板：44
- 页面状态效果图：236
- 每版阻断视觉代表状态：50
- 其余状态：作为实现参考，由状态测试、公共组件测试或人工抽查覆盖。

## 2. 为什么不再逐图阻断 236 个状态

加载、输入聚焦、提交中、成功、错误、超时等状态大量复用同一公共组件。把每个状态都放到模拟器逐张截图，会把字体抗锯齿、系统栏、动画时点和模拟器渲染差异转化为大量假失败。正确做法是：

1. 236 张图片全部保留，Codex 不得自由设计。
2. 每个公共组件和 ViewModel 状态有自动测试。
3. 每版对 8–12 个代表页面执行实际设备/模拟器截图和差异报告。
4. V1.4 对每个正式页面至少选择一个 canonical 状态做全量页面回归。

## 3. 视觉比对规则

- 固定 390×844dp、浅色、中文、字体缩放 1.0、动画关闭、固定 Fixture 数据。
- 截图先裁剪/遮罩状态栏、导航栏和动态时间。
- 结构、间距、颜色和组件缺失属于阻断；仅文字边缘抗锯齿差异不单独阻断。
- 不允许自动覆盖效果图基线；视觉基线变更必须有设计变更记录。
- 效果图只决定视觉；功能以 `feature-backend-map.csv`、API 和版本范围为准。
