# 当前任务：V1.3.0 + V1.4.0 连续视觉开发

本次任务不是重新开发整个项目，而是在当前已完成仓库基础上连续完成 **V1.3.0** 和 **V1.4.0**。

## 必须遵守
- 保留现有可运行代码与构建环境
- 不升级已能正常工作的 Gradle / AGP / Kotlin / JDK / SDK
- 不重新引入大规模模拟器门禁
- 不为每个状态建立单独 Screen
- 同一页面的不同状态必须由同一 Screen + UI State 实现
- 首次成功构建对应版本 APK 后立即交付 beta 包，不等待所有状态全部完成

## 顺序
- 先 V1.3.0：我的、会员、账户、道具、设置、客服、占位页
- 后 V1.4.0：更新检查、下载状态、维护/服务不可用、可选/强制更新弹窗、关于页生产状态
